# 程序后台运行与前台确认规则

用户于2026-10-22明确指定，适用于所有 Agent、程序、脚本、定时任务、委派任务及其子进程。

- 默认后台、隐藏窗口运行，保持用户当前窗口与输入焦点。禁止命令行、PowerShell、WSL、程序窗口、登录提示或对话框自行弹到前台；尤其禁止轮询、重试、监测和批处理反复弹窗。
- 确实必须单次前台显示时，先说明程序、用途、预计持续时间和焦点影响，取得用户对该次前台操作的明确确认后执行。后台任务授权和上一次前台许可不自动覆盖下一次前台显示。用户已明确要求本次打开或切换到该程序时，按该次授权执行。
- 先检查现有工具接口、后台模式、无头模式和隐藏启动方式。后台执行失败先查日志和修正启动方式；需要改为前台时仍先征得确认。
- 隐藏设置覆盖整条进程链。Windows Python 使用 CREATE_NO_WINDOW，按需配合 STARTUPINFO/SW_HIDE；PowerShell 的 Start-Process 使用 -WindowStyle Hidden；Node 的 spawn/execFile 使用 windowsHide:true。启动 cmd、PowerShell、WSL 和原生工具时均检查父进程与子进程。重定向日志、DETACHED_PROCESS 和计划任务 Hidden 属性须结合实际启动方式核验。
- 高频监测优先使用进程内接口、持久连接或系统接口；必须调用外部工具时，逐个调用点设置无窗口参数，保留间隔、超时和错误日志。curl、ffmpeg、ffprobe、nvidia-smi、taskkill 等辅助工具同样遵守。
- 创建计划任务、自启动项、后台服务及跨 Agent 交接时，传递本规则并检查实际启动命令。日志、临时文件和缓存沿用已核验的非 C 盘路径。
- 验证时检查真实窗口与焦点影响，或核对控制台窗口句柄和启动参数；禁止先弹出再隐藏，未经确认不得以前台试运行作验证。
- 新增或修改会启动程序的技能、脚本和配置时，同步检查本规则。已有任务如需中断或重启，先核对运行状态和用户授权。
