# 审阅入口

## 一个入口

3900 的「创作与审阅」是唯一的人审入口。作品、素材筛选、训练候选、截图标注、模型对比，全部平铺成卡片；点击直达页面。页面地址和标注存储键保持稳定，版本更新不换入口。

## 自动保存

`review-service/审阅服务.py` 伺服 HTML 时在 `<head>` 最前面注入一段脚本：

1. 打开页面先 `GET /__load?page=...`，把服务器上的标注填回 `localStorage`；
2. 之后每次 `localStorage.setItem` 同步 `POST /__save`；
3. 服务器把结果写进 `<页面所在目录>/审阅存档/<页面文件名>__<存储键>.json`，写前保留一份 `.bak`。

旧页面不用改一行就获得多端回填和后台保存。

## 生命周期

| 状态 | 进入方式 | 去向 |
|---|---|---|
| 待审 | 页面登记到清单 | 主列表卡片 |
| 已审阅完成 | 人点按钮或 `POST /api/review-status`（`action=complete`） | 约 24 小时后自动归档 |
| 历史归档 | 超时或 `action=archive` | 不进主列表，可 `reopen` 恢复 |

完成只按人的明确操作或可靠的完成记录结束；页面修改时间、任务做完、机器预填都不能替代人的确认。

## 登记

1. 页面写到 D/E/F 的真实任务目录，标题写清楚。
2. 用 `register_review.py <HTML 绝对路径>` 登记，脚本核验真实路径、3955 页面和 3900 卡片。
3. 登记后读回卡片再交付，不能只追加一行清单。

规则原文：`policies/审阅入口与归档规则.md`。
