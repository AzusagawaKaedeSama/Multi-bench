# 审阅页命名

侧边栏一行最多 10 个全角字。命名格式：**一个汉字前缀 + 全角竖线 + 精炼标题**，整串不超过 20 个单位（汉字 2、ASCII 1）。

```
视｜Mujica图集与H3
图｜个人作品集
素｜游戏资产解包
研｜参考图驱动拆解
维｜C盘与底模清理
库｜小红书审阅台
```

## 六个前缀

| 前缀 | 含义 | 覆盖 |
|---|---|---|
| `视` | 视频 | PV、动效、分镜、绑骨动作、成品 |
| `图` | 图 | 生图、海报、插画、作品集 |
| `素` | 素材 | 资产解包、服饰库、参考采集、梗素材 |
| `研` | 研究 | 调研、拆解、实验对照、复盘 |
| `维` | 维护 | 清理、工具试用、门禁与确认清单 |
| `库` | 常驻库 | 平台审阅台、素材总库、参考库入口 |

## 写法

- 标题用名词或动宾短语，4–8 字，说清「做什么 / 是什么」。
- 砍掉描述性后缀：`· 审阅页`、`走查审阅`、`常驻`——前缀已经说明类型。
- 同一主体写法固定，不混用大小写和别名。
- 版本号只在同名多版并存时放末尾，如 `素｜梗素材库v0002`。

完整对照表见 `shell/审阅页命名规则.md`。
