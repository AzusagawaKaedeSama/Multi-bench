# 图片门禁

> 作者：dsh（DeepSeek-V4.1-Flash-1017）· 2026-10-31

MOSS 与 Krea2 出的每一张图，落盘后都要过这道门。不看的图不许往下走。

## 什么时候必须调用

- 用 `分镜页.py`、`run_batch.py`、`导出原图草稿.py`、Krea2 海报引擎、本子 `run_pages.py` 或任何直接打 8190/8198 的脚本出完图之后；
- 拼页、拼视频、往 `Z-FinalOutput` 放之前；
- 用户问「今天出了多少图」「还有多少没过门禁」时。

## 三道命令

```powershell
PY = 'D:\anaconda3\python.exe'
GATE = 'D:\2-视频制作\0-工作流\图片门禁'

# 1) 出完图，立刻过一遍（出报告 + 三套确认单 + 待确认清单）
& $PY "$GATE\gate_hook.py" '<出图目录>'

# 2) 随时查状态：还有多少张没确认、必看几张
& $PY "$GATE\gate_watcher.py" --status

# 3) 发布/拼页前闸门，退出码非 0 不放行
& $PY "$GATE\check_release.py" --pending 'E:\AgentData\Work\图片门禁状态\pending.json' --strict
```

监听器 `gate_watcher.py` 常驻时不用第 1 步——8190 与 8198 的输出目录一有新图会自动处理。

## 人怎么过确认单

`E:\AgentData\Work\图片门禁状态\确认单\` 下有三个文件组：

| 文件 | 含义 | 人做什么 |
|---|---|---|
| `<日期>_不合格_NN.png` | 机器判死（手太小 / 糊 / 边缘密度太低） | 扫一眼确认删掉，不用逐张看 |
| `<日期>_必看_NN.png` | 机器判不了（被遮挡、被裁切、轮廓破碎、没定位到手） | **逐格看，在格下填「几根」** |
| `<日期>_速览_NN.png` | 手够大够清晰 | 快速扫，填「几根」 |

填在 `E:\AgentData\Work\图片门禁状态\pending.json` 里：每条把 `fingers_filled` 写成数字，`status` 写 `pass`；发现问题写 `fail` 并在 `note` 里写清哪个部位、什么问题。

## 判读口径（2026-10-31 教训）

**光看轮廓数手指会错。** 261027 那次：初华向镜头伸手，大拇指被手掌挡住，指尖只露四个凸起，我和取证子代理都判成四指，实际是五指。所以：

- 一只手要**同时看两只手做对照**——同一张画里两只手都数，有一只手对不上才可疑；
- 手背朝外、手指并拢、握道具的，先看指缝线在不在，别数指尖；
- 手指和道具（剪刀、红线、栏杆）贴在一起的，必须放到 300px 以上再看。

算法能判的只有三件事：手部框够不够大、局部糊不糊、轮廓有没有破碎。**手指数量算法判不了**，2026-10-31 实测三条视觉通道全部不通（4Router 读图超时、qwen 限流、本机无模型），不要再指望模型替人数手指。

## 出图侧的硬约束

1. **手部框高低于 160px 的图直接判不合格重抽**——这么小的手，制作时看不清、观众也看不清，本来就不该进成片。
2. 视频素材按**片段最差帧**查：H3 会在片段内把手指数改坏（261027 实测 0.25 秒还是五指，1.40 秒起最外那根消失），只看首帧必漏。
3. 失败回到生成：改提示词、换 seed、整页重抽；MOSS 单格重出会丢整页上下文，画风会变。
