## 先确定输入、输出和已有归属

分别判断“正在使用什么”和“这次要得到什么”：原始素材、精选参考、视频作品、图片作品、提示词或分析、工作流与模型、可再生过程文件、长期任务记录。下载一张参考图时，归属素材库；基于它写提示词时，另存分析结果并记录原图路径。

用户指定的目标路径优先；其次沿用已有项目或素材集合。QQ、GPT Desktop、Codex、DSH、Claude 是交办入口，保存位置由文件用途和已有归属决定。

1. 找到输入的真实原件、来源和关联任务。
2. 确定已有项目、对应模板分类和此次输出位置。
3. 执行用户当前交办的动作，记录输入到输出的关系。
4. 检查文件实际落盘位置、登记成果，并在工作台读回入口。

## 下载结束后归档

下载暂存完成且验证通过后，将原件晋升到已确认的素材库，再登记完成与交付。登记真实路径、来源、哈希和来源任务。工作台保存索引、审阅页和人工作答，原件保存到素材或项目的正式位置。

遇到正在运行的采集器，处理其中已完成且文件稳定的批次；浏览器资料、当前队列和活动输出保持原位。归档前检查实际进程与写入状态，逐项验证副本；保留旧路径兼容入口、审阅地址和存储键。带人工标注的目录一起保留。

清理只针对明确标记为可再生、无工程及成品引用、未被运行任务使用的临时数据。按冻结清单操作，记录释放量和回执。原片、精选参考、训练集、模型权重、人工标注与无法核清用途的文件按长期数据处理。
